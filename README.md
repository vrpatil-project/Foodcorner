Food Corner 🍴

Welcome to Food Corner, a simple food website created using HTML.
This website includes Veg and Non-Veg food items with images and basic details.

Users can easily explore the menu and select different food items using simple links.
The project is designed with a clean and simple HTML structure for easy understanding.

Features

- Veg Food Menu
- Non-Veg Food Menu
- Food Images
- Food Item Details
- Simple Navigation using Anchor Tags

Technologies Used: HTML
